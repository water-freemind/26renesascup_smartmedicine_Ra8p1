## 1. 用户验收要求

1. **必须先收好 Z 轴才能移动 XY 轴**（硬性约束，防 Z 撞柜/药盒）；
2. **XY 可以一起动**（并行同步移动，不允许先 X 后 Y 的串行浪费时间）；
3. 写取药逻辑测试程序：**当前零点 = 第一个药柜**，按之前的药柜设置；
4. 测试抓取逻辑（完整取药流程）；
5. **量程保护**：任何移动不得超过实测最大脉冲数（X 406mm / Y 296.3mm / Z 151.8mm / 抓手 28000），超量程会堵转。

## 2. 实测关键结论（J-Link 探针，决定实现方式）

| 结论 | 影响 |
|------|------|
| **各轴"回零完成"应答只有 Z 可靠**（arrived=[0,0,1,0]，Y/X/抓手无 9A 02 6B） | 回零必须用固定时序（Z→2s→其余→1.5s），等应答会每轴 20s 超时 |
| **"移动到位"应答只有 X 会回 FD 9F 6B，且随机丢帧**（同步移动时 Y/抓手收不到） | 移动用"距离/速度"估算固定等待（下限 1.5s 上限 8s），收到应答仅提前结束 |
| **同步模式（ZDT_SyncTrigger）下电机不动** | 一律 sync=false 各轴独立发命令，不调 SyncTrigger |
| **CAN 命令帧偶发丢失**（X/Y 随机不动，两次结果相反） | 移动命令**连发 3 次（间隔 5ms）**，轴间再加 10ms——与调试页 JOG、用户原 `Move_XY_To_mm`（X/Y 间 vTaskDelay(10)）同一思路 |
| **Z 顶量程堵转后移动命令全不执行** | PH_ENABLE 阶段每轮 `Gantry_UnprotectAxes`（0E 52 解除堵转） |
| 线程优先级：Motor=3 最高、Camera=2、LVGL=1 | 已确认非优先级问题，排除 |

## 3. 检查发现的问题（已修复）

### 3.1 旧应用层取药逻辑已失效（`ZDT_app.c` 的 getMedicine/storeMedicine）
- 依赖的 `g_is_x_done / g_is_y_done / g_is_z_done / g_is_catch_done / is_cd / is_receving / g_motor_queue`
  全工程**只有 extern 声明、无任何定义**（grep 确认）→ 链接不报错是因为从未被调用；
- 旧流程是阻塞式 `while(!is_done)` 忙等 + 直接调 ZDT，与现在的 `gantry_robot` 命令队列体系脱节；
- 旧流程在 **Z 伸出状态下移动 XY（y+30 抬药）**，违反"先收 Z 再动 XY"约束；
- 旧代码 Z 伸出用 `200000` 脉冲，远超实测行程 6600 → 会堵转（用户原工程 ZDT_app.c 未链接进固件，仅作参考）。

### 3.2 gantry_robot 到位事件未接通（关键缺陷）
- `Gantry_NotifyAxisDone` 全工程**无调用者** → 正式流程发出移动命令后永远等不到到位，
  会在 15s（回零 20s）超时进入 FAULT；
- **修复**：`gantry_debug.c` 的 CAN 回调识别到位应答（`FD 9F 6B` 移动到位 / `9A 02 6B` 回零完成）
  时顺带调用 `Gantry_NotifyAxisDoneFromISR(axis, true, NULL)`（ISR 安全，只写标志）。
- **后续改为固定时序为主、应答仅提前结束**（实测应答不可靠，见 §2）。

### 3.3 gantry_robot 不支持抓手(CATCH)轴的正式流程
- `Gantry_Home`/`Gantry_EnableAxes` 掩码只 `& GANTRY_AXIS_MASK_ALL`（XYZ），CATCH 被丢弃；
- `Gantry_SetLogicalPosition` 的 homed_axes 也 `& MASK_ALL`，CATCH 永远 "not homed" →
  `Gantry_MoveAxisTo(CATCH, ...)` 一律返回 `GANTRY_ERR_NOT_HOMED`；
- **修复**：三处掩码改为 `GANTRY_AXIS_MASK_VALID`（XYZ|CATCH），回零阶段
  "Z 先单独回零，再 X|Y|CATCH 一起回零"。

### 3.4 移动等应答 → err=7 超时（改固定时序估算）
- 移动应答不可靠（§2）→ 等应答会 15s 超时 FAULT 卡流程；
- **修复**：`s_move_est_at` 按 `距离脉冲 × 4000 / 速度` 估算各轴耗时取最大，
  下限 1500ms、上限 8s；到期 `finish_active_command()`（不 FAULT）；
  收到的到位应答仅提前结束。

### 3.5 取药流程卡死（FAULT 时永远 return，不报错）
- `pickup_test.c` 的 `s_waiting` 里 `if (!Gantry_IsIdle()) return;` 在 FAULT 时
  `state != IDLE` 恒真 → 永远等"上一条命令完成"，失败永远不显示；
- **修复**：**先查 FAULT/STOPPED 再查 idle**，故障时立即 `fail("err=N")` 停流程。

### 3.6 夹爪方向 / 收量 / 量程问题（按用户逐条纠正）
- **夹爪方向**：一度设成正脉冲 → 用户纠正"夹爪明明是负的，往里收"→ 恢复 `-grip_pulses`；
- **Z 收回目标**：用户原工程用 100 脉冲，但用户明确"收回到（0）不是收回多少"→ 收回 0；
- **Z 伸出量**：两次错设 133200 / 200000 脉冲都超量程 → **实机堵转两次**。
  用户实测 Z 最大 6600 脉冲 = 151.8mm → 恢复 151.8 标定 + PH_ENABLE 解堵转；
- **Y 量程**：最初按 281.2mm（12050 脉冲）→ 用户实测最大 12700 脉冲 → **Y 0~296.3mm 定稿**；
  第三层原 299 / 281 均超行程（err=6 SOFT_LIMIT）→ 改为 296.3；
- **抓手量**：用户要求"改成最大脉冲的一半"→ `grip_pulses = 14000`（-28000 的一半）。

### 3.7 暂存区坐标超行程
- 旧 `store_area_y=299` 超出 Y 轴行程 → **修复**：(0, 280)（行程内）；store_x 50→0（用户要求取药区 x=0）。

### 3.8 量程三层防护（用户强调"一定要注意最大脉冲数不要超出量程"）
1. **参数页校验**：P_SHELF_Y ≤ 296.3、P_SLOT_WIDTH 固定值 30~406/格数、P_BOX_WIDTH 10~200、
   P_STORE_Y ≤ 296.3、P_Z_REACH ≤ 151.8、P_GRIP ≤ 28000，超限拒绝输入；
2. **OSPI 自愈**：`clamp_ranges()` 在 `PickupParams_Init` 加载后钳制超量程值并回写主/备份；
3. **点击前检查**：取药调试页格子点击前换算 X/Y，超量程提示"未启动"不发命令。

### 3.9 机械参数（用户提供，已核实）
- **步进电机**：1.8°（200 步/圈），**XYZ 微步 16 细分 → 3200 脉冲/圈**；
  与实测标定自洽（X/Y 74.7mm/圈、Z 73.6mm/圈），标定保持实测值。
- **夹爪开口**：两指间距 0 脉冲=125mm（归零全开）、-28000 脉冲=52mm（收到底），范围 52~125mm；
  **用户确认：不会放夹爪最小都夹不住的东西**（药盒宽度在夹爪可夹范围内）。
- **格子宽度约束**：下限 = 夹爪最小间距 **35mm**（3.5cm，用户修正）；自动 = 药盒宽+10mm 余量（药盒宽度因药而异，参数页可调）。

## 5. 取药调试页（用户实机操作）

- **入口**：Device 页 → 右下角"**取药调试**"按钮（(452,416)，与自检不重叠）。
- **页面**：药柜格子矩阵按参数生成（3 层 × 3 格），**镜像布局**（对应药柜实际视角：第1层在最下面一排、第1格在最右边一列）；层号标签在左。
- **点格子取药**：点击某格 → 设置测试目标 → 启动完整取药流程，状态行实时显示阶段文字。
- **全体归零**：Z 先回零 → X+Y+抓手回零（固定时序 ~3.5s，回到第一个药柜零点）。
- **急停**：Gantry_EmergencyStop（err=9 为急停正常反应，点"解除"恢复）。
- **状态行**：优先显示取药流程进度/结果；空闲显示"点击格子开始取药"；FAULT/STOPPED 显示 "机械臂故障/已停止: err=N"。
- **流程阶段**：使能电机（含解堵转）→ 回零 → XY→药柜(第n层第n格) → Z伸出151.8mm → 夹爪闭合(-14000) → **Z收回0（先收Z再动XY）** → XY→暂存区(0,280) → Z伸出放下 → 夹爪张开 → Z收回0 → **完成**。
- **失败处理**：`取药测试失败：err=N`（错误码见 gantry_robot.h）；撞限位/堵转 → 先点"解除"再重新点格子。

## 6. 测试流程（上电验收顺序）

1. 上电 → 约 5~10s 后自动回零：Z 先单独回零 → 2s → X+Y 一起回零 → 抓手回零（~3.5s 完成）；
2. Device → 参数设置：改 层高/格子宽度/其他 → 保存（写 OSPI，即时生效）；
3. Device → 取药调试：点第1层第1格（右下角）验证完整流程；再点第3层（最上排，Y=296.3mm 行程顶）；
4. 观察：**任何 XY 移动前 Z 必先收回**；XY 两轴同时动；
5. 失败时状态行显示 err=N；撞限位/堵转 → 先点"解除"再重新点格子。
