# LVGL 模拟界面任务计划

## 目标

仅修改 `gui/` 目录，在 GUI Guider 中完成可继续编辑、可在桌面模拟器运行的 640×480 医疗卡片式界面；暂不接入 RA8P1 摄像头、CAN、电机、Wi-Fi 或其他硬件接口。

## 固定设计决策

- 整体方案：医疗卡片式。
- 扫码方案：480×360 大预览区加右侧状态区。
- 配色：医疗蓝、浅灰白背景、绿色成功、橙色警告、红色错误。
- 操作：触摸为主，保留返回、确认和急停的界面映射。
- 页面：启动、首页、取药任务、药品扫码、药品识别结果、存药管理/取药日志、设备状态。
- 所有硬件行为使用模拟数据和模拟交互。

## 范围约束

- 允许修改：`gui/**`。
- 禁止修改：`src/**`、`ra/**`、`ra_gen/**`、RASC、根目录 CMake 和硬件驱动。
- 不直接把模拟器硬件桩代码耦合到 RA8P1 应用层。

## 已知风险

- GUI Guider 设计文件不能可靠地由手写 C 代码反向生成。
- GUI Guider 版本与工程格式不一致时，需优先保持 `.guiguider` 可打开。
- GUI Guider 自动生成文件可能覆盖手工修改，因此界面结构优先更新 `.guiguider`，模拟逻辑放入 `custom/`。
- 用户已在 GUI Guider 中调整 Boot 封面配色；本轮禁止运行整页重建脚本或改写 Boot 节点。
- `.guiguider` 是 GUI Guider 专有 JSON，必须使用 GUI Guider 2.0 已验证节点格式，不能凭空猜字段。
- 当前医疗界面由 C 代码动态创建；迁移后必须避免同时创建两套页面和重复定时器。
