# XYZ龙门机械臂应用接口计划

## 目标

审计现有ZDT电机代码，在完全保留已实测底层指令、报文和到位应答的前提下，为三轴门框式龙门机械臂增加清晰、安全、可扩展的应用层接口。

## 边界

- 不修改 `src/driver/src/ZDT_drv.c` 的协议编码和发送指令。
- 不改变既有ZDT CAN ID、到位应答和已验证动作语义。
- 新接口位于应用层，由Motor线程独占执行底层驱动。
- 未知机械尺寸、脉冲当量和限位方向采用显式配置，不擅自假定。

## 阶段

- [完成] 1. 审计ZDT驱动、应用层、Motor线程和构建关系
- [完成] 2. 设计坐标、状态、安全和异步命令接口
- [完成] 3. 实现XYZ龙门应用接口
- [完成] 4. 编译与静态验证
- [完成] 5. 更新总览与交接记录

## 验收条件

- 原有ZDT底层文件无协议修改。
- 支持初始化、使能、回零、绝对/相对移动、单轴移动、停止、状态与坐标读取。
- 运动命令通过Motor线程队列串行执行。
- 软限位、回零状态和参数错误可被应用层识别。
- 工程至少完成当前可行的ARM编译/静态检查。

## 错误记录

| 错误 | 次数 | 处理 |
| --- | ---: | --- |
| 暂无 | 0 | - |
| 整块补丁未匹配Motor线程换行上下文 | 1 | 拆分为新增文件与最小线程补丁，避免重复同一操作 |
| `cmake` 不在当前PowerShell PATH | 1 | 从现有CMakeCache读取实际工具路径后构建 |
| 默认GUI构建被旧 `guider_ui.Copy` 引用阻塞 | 1 | 新模块已编译；清零新警告后用 `RA8P1_GUI_ENABLE=OFF` 基线验证链接 |
