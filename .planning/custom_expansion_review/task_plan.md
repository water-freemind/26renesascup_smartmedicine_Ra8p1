# 自绘扩展板原理图审查计划

## 目标

把自绘两页 RA8P1 扩展板与官方板、当前 RASC 和器件资料逐网对照，找出损坏、启动、引脚和外设风险，并完整归档。

## 阶段

- [x] 核对截图中的连接器、网络和器件功能。
- [x] 对照官方接口和当前引脚复用。
- [x] 核对 CAN、ATX、ESP-01S、摄像头、MIPI 和 PWM。
- [x] 按严重程度整理错误、疑点和建议。
- [x] 建立详细硬件文档，同步总览与 README。

## 原则

- 截图可确认的问题直接指出；依赖封装方向、BOM 或模块版本的项目标为待确认。
- 优先处理可能损坏硬件或导致打板报废的问题。
- 不修改用户 EDA 源文件，只保存结论和修改清单。
